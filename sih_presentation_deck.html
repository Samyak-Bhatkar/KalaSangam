🔄 8-Step Autonomous Data Pipeline Zero-Drop Queue

1. Frontend → Backend: Capture & Ingestion (REST/WebSocket from Flutter, React, 2G IVR)
2. Backend → Vision (Branch 1): Image payload → rembg BiRefNet + OpenCV 6500K balancer
3. Backend → Speech (Branch 2): Audio payload → Bhashini Indic ASR + Gemini 2.5 Flash entity parsing
4. Vision + Speech → Pricing (Merge): CLIP visual similarity + extracted metadata → Vyapar-Niti wage floor
5. Pricing → Security: Finalized listing → 2D DCT watermark + SHA-256 GI hash + Dynamic QR
6. Security → Backend: Persist verified listing to SQLite WAL & Postgres state ledger
7. Security → Commerce: Schema serialization for ONDC Beckn Retail v1.2 & GeM procurement
8. Commerce → Frontend: Live listing feed to artisan dashboard & buyer-facing consumer apps
