# UI/UX & Design System Guidelines: ShilpSetu (KalaSangam)

## Design Persona & Standard
> **Standard**: Staff Product Designer at Apple + ex-Airbnb Design Lead + Google Material Design 3 + SIH Grand Finale Judge criteria.
> **Core Objective**: Create a premium, elegant, trustworthy, and memorable interface that feels modern and world-class **without using dark mode**.

---

## 1. Core Visual Principles
1. **Light Mode First (No Dark Theme)**:
   - Clean, luminous, editorial surfaces inspired by Apple product pages and Airbnb craft experiences.
   - Canvas background: `#F8F9FA` or `#FFFFFF`.
   - Card surfaces: Crisp `#FFFFFF` with ultra-fine border `#E5E7EB` (or `rgba(0, 0, 0, 0.06)`) and soft, natural ambient shadows.
   - Avoid dark, muddy, or brooding backgrounds.
2. **Color Psychology & Accessibility (WCAG 2.1 AA Compliant)**:
   - **Primary Tint**: Deep MoSJE Saffron / Terracotta Amber (`#B45309` / `#C2410C` accents) paired with refined Navy/Slate (`#0F172A` / `#1E293B`) for high contrast text.
   - **Success / Authenticity**: Emerald Green (`#047857` / `#059669`) for verified craft badges, GI tags, and living wage confirmations.
   - **Neutral Palette**: Crisp off-white (`#F8F9FA`), warm stone gray (`#F1F5F9`), border gray (`#E2E8F0`), muted text (`#64748B`), dark body text (`#1E293B`).
   - **Strict Rule**: Avoid neon colors, oversaturated primary buttons, and distracting multi-color rainbow gradients.
3. **Typography & Visual Hierarchy**:
   - Modern, humanist typography: SF Pro Display / Inter / Plus Jakarta Sans.
   - High contrast hierarchy: bold headlines, subtle uppercase metadata tags with letter-spacing (`tracking-wider`), and comfortable body text (minimum 14px / 16px).
   - Generous line heights (`leading-relaxed`) to prevent cognitive overload for rural artisans and judges.
4. **Generous Whitespace & Clutter-Free Layout**:
   - Breathing room: 24px - 32px padding on cards, 48px - 64px vertical spacing between sections.
   - Focus on one primary action per screen/card (e.g. 1-Tap Voice Record, Compare Slider, Publish).
5. **Subtle, Purposeful Motion**:
   - Micro-interactions: 150ms-250ms smooth ease-in-out transitions on hover/press.
   - Never use dizzying spinning animations or jarring popups.
6. **Dual Accessibility (Artisan Simplicity + Judge Presentation)**:
   - **For Rural Artisans**: Large tap targets (min 48x48px), iconography + dual-language text (Hindi + English), voice readbacks, visual confirmation banners.
   - **For SIH Judges**: Clear metrics (latency, wage formula, ONDC compliance, before/after comparisons), trustworthy certifications, institutional MoSJE branding.
